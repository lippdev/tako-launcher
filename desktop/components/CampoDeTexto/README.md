# CampoDeTexto

Campo de texto em diálogo (nome de coleção, chave de API): diálogo S com o campo de 44 (o da busca, com borda clara de foco), ajuda embaixo, Cancelar e o primário. Abre com o texto selecionado; Enter confirma, Esc cancela.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
