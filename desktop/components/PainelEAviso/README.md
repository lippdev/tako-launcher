# PainelEAviso

Movimento das camadas: painel desliza de 102% para 0 em 450 ms (véu em 300); diálogo com véu em 250 ms e caixa subindo 12 em 350 ms; aviso sobe 20 px em 350 ms. Tudo na `curva-entrada`. Reduzir animações: na hora.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
