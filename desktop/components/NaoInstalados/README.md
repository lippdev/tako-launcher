# NaoInstalados

Jogos que estão numa loja mas não no PC (SRC-005) ficam na lista com o nome em `#858585` e o ícone em cinza (grayscale 80%, brilho 70%). "Mostrar só › Jogos instalados" esconde. Na página do jogo, o primário vira **Instalar** e, baixando, "Baixando 30%" com a barra no pé (ver EstadoNaoInstalado).

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
