# LojaEncontrada

Linha de loja ou emulador no onboarding, no padrão da LinhaDeConfiguracao (58): ícone/logo, nome, pasta ou sistemas, e à direita a quantidade com ponto verde, "Não instalado" apagado, ou o que falta com a ação.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
