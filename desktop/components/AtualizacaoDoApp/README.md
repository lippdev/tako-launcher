# AtualizacaoDoApp

Procurar atualizações (menu da marca ou Configurações › Geral › Atualizações): o botão Procurar vira um giro enquanto procura; a linha passa a dizer "Está tudo em dia · conferido agora" e o Aviso confirma ("O TAKO está em dia"). Achou: baixa em segundo plano (AtividadeNaBarra) e, pronto, o diálogo "Atualização pronta" com as novidades, Depois · **Reiniciar agora**.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
