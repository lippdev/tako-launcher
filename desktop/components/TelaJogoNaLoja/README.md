# TelaJogoNaLoja

A mesma página do jogo para um jogo que a pessoa não tem.

- Dados à esquerda viram números da loja: tempo médio, nota, jogadores (GrupoDeBlocos sobre a arte).
- Preço acima das ações (desconto, riscado, final; "Promoção acaba em 3 dias · economize …").
- Ações: ♥ lista de desejos, Pôr no carrinho, **Comprar · preço**.
- Situação: JOGO BASE, ou "x% · PROMOÇÃO".

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
