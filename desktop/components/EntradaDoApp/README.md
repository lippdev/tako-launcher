# EntradaDoApp

Abertura do TAKO: barra, lista, título, destaque, Voltar a jogar e seções entram em escada de 70 ms (opacidade, desfoque e sobem 14). Total ≈ 1 s. Com Reduzir animações, aparece tudo de uma vez.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
