# Conquistas

"Suas conquistas" (ou "Conquistas" na loja): total e barra branca de progresso; linhas com ícone de 46, nome, descrição e a % de quem tem; conquista feita com ícone azul e ✓ verde. Hover sobe 3 px. Por último, "Ver todas as conquistas". Na loja: "Compre o jogo para acompanhar".

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
