# ControleDeslizante

Valor contínuo é deslizante arrastável: trilho de 180×4 (parte cheia branca), bolinha branca de 18 com sombra, valor à direita (Poppins 600, números tabulares, com a unidade: 60%, 28px). Volume, zona morta, desfoque e opacidade do Liquid Glass.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
