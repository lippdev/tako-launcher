# AssistenteInicial

Ao criar um perfil novo, os primeiros passos abrem num diálogo sobre a biblioteca: passos no topo (feitos com ✓, atual em branco), "PRIMEIROS PASSOS · 2 DE 3", título, frase, lojas em linhas com chave, e Pular por agora · Voltar · **Continuar**.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
