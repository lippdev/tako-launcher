# MenuDoTako

O menu da marca: Configurações, Procurar atualizações, separador e **Sair** (vermelho `error`). Menu padrão (MenuDeContexto): 220 de largura, raio 12, `surface-raised`, contorno `line-strong`, `shadow-float`, itens de 34 com ícone de 15. Abre 6 abaixo da marca.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
