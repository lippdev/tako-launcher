# EstadoNaoInstalado

Jogo da biblioteca de uma loja que não está no PC (SRC-005): situação NÃO INSTALADO, nome apagado na lista, Tamanho no disco "—", Situação "Não instalado" sem ponto, primário **Instalar**. Baixando: "Baixando n%" na situação, no primário (barra) e na lista (% + barra no ícone).

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
