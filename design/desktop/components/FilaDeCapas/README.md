# FilaDeCapas

Configurações › Capas e dados › Revisar capas (ART-001/002/003): "Aceitar as 12" de confiança alta num grupo próprio; depois a fila, uma linha por jogo: nome e origem, capa atual (ou "Sem capa" tracejado) → capa proposta, confiança em texto e em três barrinhas (verde/amarelo/vermelho) com o motivo, Aceitar e, abaixo de alta, Escolher outra.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
