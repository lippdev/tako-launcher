# BibliotecaCategorias

A biblioteca em fileiras de capas por categoria (Lista · Grade · **Categorias**, seletor segmentado no título) com "Agrupar por" (Situação, Coleção, Etiqueta, Gênero, Loja, Instalação): uma fileira por grupo, com contagem e ‹ ›, 7 capas por largura.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
