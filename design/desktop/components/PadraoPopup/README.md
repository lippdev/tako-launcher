# PadraoPopup

Todo popup segue o Dialogo: título que diz o que aconteceu (pergunta quando pede decisão), ✕ sempre; uma ou duas frases; ação de texto à esquerda, secundária contornada e **um** primário por último. Tamanhos S 440, M 540, L 680 (com mídia). Véu escuro: é uma decisão que bloqueia; o que não bloqueia é PainelLateral ou Aviso.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
