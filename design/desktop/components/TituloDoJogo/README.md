# TituloDoJogo

O nome do jogo é o **logo** dele (até 440×140 na página, 320×100 na Visão geral, `object-fit: contain`, alinhado embaixo à direita), com sombra `0 6px 24px` a 60%. Logo escuro: invertido. Sem logo: o nome em texto, Poppins 54/800. Acima, a etiqueta de situação; abaixo, a descrição (13,5, até 3 linhas na loja).

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
