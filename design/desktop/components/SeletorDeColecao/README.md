# SeletorDeColecao

Coleções entram pelo menu Ordenar, ver e filtrar (seção Coleção, com a quantidade de cada uma, Nova coleção… e Organizar coleções). Com uma coleção ativa, um chip "Roguelikes · 6 ×" fica no lugar de Visão geral; o × volta para Todos.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
