# MenusEDicas

Movimento dos menus e das dicas.

- Menu: opacidade 150 ms e de −4 px / escala 0,98 para o lugar em 200 ms (`curva-entrada`). Clique fora ou Esc fecha.
- Dica: aparece em 150 ms; na barra de cima fica 8 abaixo do botão, centrada; na lista recolhida, 12 à direita do ícone. Na lista aberta não há dica (o nome já está escrito), menos no botão de recolher.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
