# CartaoDetalhes

Detalhes em chave/valor (linhas de 39, alternadas em `#111`): Desenvolvedor, Publicadora, Lançamento, Tamanho no disco, Situação (ponto verde quando instalado). Abaixo, o **radar de gênero** (5 eixos) em caixa própria com rodapé "Gênero do jogo"; abre do centro em 900 ms e mostra os pontos no hover.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
