# EtiquetasDoJogo

Etiquetas da pessoa (LIB-002) são chips com × (alvo de 24, `aria-label` "Tirar Zerado"); o campo "+ Etiqueta" é um chip tracejado; as sugestões abrem num MenuDeContexto com a quantidade de jogos e "Criar …". Em Detalhes: até 3 chips + "+2".

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
