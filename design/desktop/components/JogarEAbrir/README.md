# JogarEAbrir

O primário do jogo em cada estado: **Jogar** (▶) → **Abrindo…** (giro no chip) → **Voltar ao jogo** (controle) com ✕ Encerrar ao lado; não instalado **Instalar** (↓) → **Baixando 30%** (⏸, barra no pé; pausado: "Pausado 30%" e ↓); com atualização **Atualizar** (cor de estado). Ao abrir, Aviso com o polvo: "Tentáculos no controle · abrindo …".

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
