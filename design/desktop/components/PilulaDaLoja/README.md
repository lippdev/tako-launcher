# PilulaDaLoja

Os chips do canto superior direito da página do jogo, a 76 do topo: situação do jogo (só na biblioteca, ver StatusDoJogo), sistema (Windows) e Compartilhar ("Link copiado"). Chip de 32, raio 9, fundo escuro translúcido com desfoque.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
