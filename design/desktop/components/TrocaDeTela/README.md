# TrocaDeTela

Troca de vista (Loja, Visão geral, página do jogo, Configurações): a que sai some com escala 0,985 (450 / 550 ms); a lista abre e recolhe em 500 ms, com os ícones crescendo para 46 em 450. Entrar e sair da loja e das configurações esconde a lista (largura 0).

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
