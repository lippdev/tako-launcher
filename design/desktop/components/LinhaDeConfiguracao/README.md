# LinhaDeConfiguracao

Linha de configuração dentro de um grupo (raio 16, `surface`, contorno `line-strong`): mínimo 64, padding 12 14 12 18, linhas separadas por `line`; título 14/600 e descrição 12,5 (`text-muted`); controle à direita: chave (46×28), seletor, botão contornado, ou valor + › (linha clicável). Linha de perigo com título vermelho.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
