# CartaoSessoes

A **barra de dados** sobre a arte: Última sessão · Tempo de jogo · Metacritic, separados por linhas de 1 branco 22%. Ícone de 20, rótulo 12/700 em caixa alta (72%), valor 15/600 com sombra de texto para ler sobre qualquer arte. Metacritic com a nota numa etiqueta colorida (verde 75+, amarelo 50–74, vermelho até 49) e o veredito ("Aclamação universal").

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
