# PerfilFamilia

Perfil › Família (UX-004): à esquerda os perfis do PC (o escolhido como item ativo), à direita grupos de linhas: Hoje (tempo usado, barra `role="progressbar"`), Limites (tempo por dia, horário, classificação — seletores) e Acesso (PIN, Mostrar a Loja, jogos acima da classificação). Só o responsável vê esta aba.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
