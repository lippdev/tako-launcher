# TelaJogoRolada

A página do jogo rolada: conteúdo à esquerda, dados à direita.

- Esquerda (1,16 fr): CartaoTrailer, capturas com barra de rolagem fina, texto da página (CartaoSobre), Recursos (2 colunas) e Requisitos (Mínimo · Recomendado).
- Direita (1 fr): CartaoDetalhes, radar de gênero e, fixos 78 abaixo do topo, GrupoDeBlocos (tempo para zerar, conquistas, downloads, jogando agora) e Conquistas.
- A barra fina de cima fica com fundo (canvas 82% + desfoque 18) e mostra capa + o primário.
- Fim: "Parecidos" em fileira de capas.

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
