# PassosDoOnboardingMovimento

Troca de passo do onboarding com a mesma escada da troca de jogo: progresso, título, frase, conteúdo, ações e rodapé entram com 55 ms entre eles (opacidade, desfoque, sobem 14).

Base: protótipo do mantenedor (`launcher.html`, out/2026), tema TAKO. Prévia gerada por `gen/rebrand.py` a partir do protótipo rodando, com arte de exemplo.
